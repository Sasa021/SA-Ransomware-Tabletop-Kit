# Evidence

This folder is for the notes and photographs you collect when you run Exercise Wharf Lantern. It starts empty on purpose. A stocked evidence folder in the first commit would be a fabricated sitting.

## What to put here, after a real run

- The completed scribe log, or a scan of the paper log
- Photographs or notes listed in [docs/screenshot-checklist.md](../docs/screenshot-checklist.md)
- Drafts the room produced and rejected
- The after action report, if you want it beside the log

## What this repository does with those files

`.gitignore` ignores everything in this folder except this README. You can keep local photos in the working tree without publishing them. If you decide a redacted page belongs in the portfolio, remove or narrow that ignore rule in a later commit and say, in the commit message, that the people in the room agreed.

## Before anything is published

- Remove faces, unless you have consent.
- Remove phone numbers, e-mail addresses, and identity numbers.
- Remove any real workplace story that surfaced in the sitting.
- Do not add a ransom address, a payment record, or a malware sample. Those are out of scope for this kit, and they do not belong in a public repository even as an illustration.

## How to refer to the evidence from the README

In **Results and lessons learned**, point to the file names you actually have. If the files stay private, say "scribe log held locally, not published" and still fill the decision lines from that log. Unpublished is honest. Invented is not.
