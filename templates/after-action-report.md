# After action report

Exercise Wharf Lantern, Harbourline Discretionary (Pty) Ltd (fictional).

Write this from the scribe log after a real sitting. If a section did not happen, leave it blank or write "not done". Do not backfill a decision the room never made. Do not add participant praise, scores, or lessons you wish the room had learned.

**Not legal advice.** If you describe a notification duty, use the same limits as [regulatory/breach-notification-guide.md](../regulatory/breach-notification-guide.md). In particular, do not turn an uncertain commencement date or an unread template cover page into a claim that the firm complied with a deadline.

## 9. What this report is not

- It is not a forensic report. Entry path stays unconfirmed unless your room was given a fact this kit does not contain.
- It is not participant feedback. Quotes need consent and belong in the README results section as well.
- It is not a real notification to the Information Regulator, the Financial Sector Conduct Authority, the Prudential Authority, or the South African Police Service.
